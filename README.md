🏆 Overview

The ARES-X Games Collection is a curated library of MIT-licensed, high-performance HTML5/JavaScript games used by the ARES-X AI Discord Bot.
All games are designed to be:

⚡ Fast (60 FPS)

🎮 Playable directly in browser

📱 Mobile-friendly

🔒 Ad-free & clean

🧩 Organized into separate folders

🚀 Hosted on GitHub Pages for instant access

This repository powers the /playgame command inside the ARES-X Discord ecosystem.
